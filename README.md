# TabNest

> 一个本地优先的 Chrome 新标签页工作台：集中管理打开的标签、书签、常用链接与可恢复会话。

本仓库是 [Acorn2/tab-nest](https://github.com/Acorn2/tab-nest) 的公开 fork，并在其基础上维护 TabNest v1.2.0。

## 功能

- **打开标签管理**：按域名或窗口查看当前标签，搜索、批量选择、关闭或移动标签；自动提示并处理重复标签。
- **书签看板**：把一个或多个书签文件夹平铺到新标签页；支持文件夹内搜索、折叠、显示数量设置与批量打开。
- **书签资料集**：将挑选的书签保存为可命名的资料集，之后可一键重新打开。
- **快捷链接**：创建、排序和编辑个人常用链接，并选择在当前或新标签页打开。
- **会话保存与恢复**：保存当前窗口或全部窗口的工作会话，随时恢复；未读会话有提醒标记。
- **个性化与本地优先**：中英双语、明暗主题、自定义纯色或背景图片。数据保存在浏览器本地，不依赖账户或后端服务。

## v1.2.0 相对上游的改动

- 将扩展整理为可直接加载的 Manifest V3 项目根目录，并提供发布包 `TabNest-v1.2.0.zip`。
- 扩展书签功能：支持多个书签看板、看板内检索、文件夹导航、批量选择与资料集保存/一键打开。
- 强化标签页工作流：新增域名/窗口两种视图、重复标签提醒和批量处理。
- 完善个性化：增加中英语言切换、明暗主题、纯色背景与本地背景图。
- 调整界面与文案，改善新标签页的信息层级和操作反馈。

## 安装

### 直接安装开发版

1. 下载或克隆本仓库。
2. 打开 `chrome://extensions`。
3. 打开右上角的“开发者模式”。
4. 选择“加载已解压的扩展程序”，并选择本仓库目录。

### 使用 Release 包

1. 从 [Releases](https://github.com/Imp7019/tab-nest/releases) 下载 `TabNest-v1.2.0.zip`。
2. 解压 ZIP 后，按上述“直接安装开发版”的第 2–4 步加载解压后的目录。

## 所需权限

| 权限 | 用途 |
| --- | --- |
| `tabs` | 展示、整理和恢复 Chrome 标签页与窗口。 |
| `bookmarks` | 读取书签文件夹和书签内容，构建书签看板与资料集。 |
| `storage` | 在本地保存设置、快捷链接、会话和背景配置。 |
| `favicon` | 显示网页及书签图标。 |
